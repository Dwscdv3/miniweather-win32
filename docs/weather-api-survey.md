# 国内天气 API 调研（2026-10-21）

针对"中国境内、免费、比 Open-Meteo 更准且能到区县"这个目标做的横向对比。所有额度/价格都可能变动，
接入前请以官网为准；下面标注的实测数据是本机当天的真实返回。

## 一、现状：Open-Meteo 到底卡在哪

**1）地理编码只到地级市**（这就是"只精确到地级市"的直接原因）

```
GET https://geocoding-api.open-meteo.com/v1/search?name=西湖区&count=3&language=zh
→ {"generationtime_ms":0.099658}          ← 没有 results，搜不到

GET .../search?name=朝阳区 ...
→ {"generationtime_ms":0.08583069}        ← 同样为空
```

它基于 GeoNames，地名库里没有中国区县一级条目，所以"西湖区""朝阳区"这种检索直接空结果。

**2）中国境内用的是境外数值模式**，实况偏差肉眼可见。同一坐标（北京 39.9042,116.4074）、同一时刻：

| 模型 | 温度 | 湿度 | 说明 |
| --- | --- | --- | --- |
| `best_match`（当前默认） | 6.5 ℃ | 39% | 自动挑选，中国区通常落到境外模式 |
| `cma_grapes_global` | 6.6 ℃ | 27% | 中国气象局 GRAPES，15 km，6 小时更新 |
| `icon_seamless` | 5.2 ℃ | 46% | 德国 DWD，2–11 km |
| `gfs_seamless` | 9.8 ℃ | 17% | 美国 NOAA，3–25 km |

四个模式温度能差 4.6 ℃、湿度差 29 个百分点。"体感不准"主要来自这里，而不是界面。

**3）商用要付费**（$29/月起）。个人/非商用没问题。

### 各家补充说明

- **和风**：目前中国区能力最全的免费方案。GeoAPI 支持中文模糊搜索并返回区县 `LocationID`，
  `/v7/weather/now`、`/v7/weather/24h`、`/v7/weather/7d` 一套齐活，还有预警和空气质量。
  注意它现在有 API Key 和 JWT（Ed25519）两种鉴权，C 里用 API Key 最省事。
- **高德**：一个接口 `restapi.amap.com/v3/weather/weatherInfo?city=<adcode>&extensions=all`，
  返回实况 + 4 天预报，字段干净；缺点是**没有逐小时**、预报每天只更新 3 次，做曲线图不够用。
- **心知**：免费版只覆盖 370 个主要城市，比 Open-Meteo 更窄，免费版还砍到 2 个要素 + 3 天预报，不划算。
- **彩云**：分钟级降水是真强项，但其他维度薄，适合做"要不要带伞"的插件而不是完整天气页。
- **聚合数据 / UAPIS 之类**：额度极小（50 次/天）或来源不明、稳定性无保证，不建议进产品。

## 三、结论与建议

1. **首选和风天气免费订阅**。理由：唯一同时满足「区县级 + 逐小时 + 7 天以上 + 预警 + 免费」的方案。
   额度算账：本应用单城市 10 分钟刷新 = 144 次/天，就算 5 个城市轮流看也远低于 1000 次/天。
2. **次选高德**，如果你想 5 分钟接完、且能接受"没有逐小时曲线"。此时刷新间隔建议放宽到 30 分钟
   （5000 次/月 ≈ 166 次/天）。
3. **暂不换**的话，把 Open-Meteo 的模式显式指定为中国气象局的 GRAPES，一行参数就能让实况更贴国内：

   ```
   &models=cma_grapes_global
   ```

   代价是分辨率 15 km、6 小时更新一次（境外模式是逐小时），且区县级仍然不支持。
4. **想在 Open-Meteo 上硬上区县**（不推荐）：用高德/和风只做地理编码拿区县经纬度，天气仍从
   Open-Meteo 取——但 11–15 km 的网格本身分辨不出区县差异，属于自欺欺人。

## 四、如果真接入，改动面有多大

`src/api.c` 是唯一的数据入口，`weather_fetch()` 返回统一的 `Weather` 结构，UI 层完全不感知供应商。
换 API 只需要替换这个函数内部的 URL 构造与字段映射（约 100 行），`main.c` / `ui.c` 不用动。

建议的落地方式：

- Key 存注册表 `HKCU\Software\MiniWeather\ApiKey`（和城市列表同处）；
- 有 Key 走和风，没有 Key 自动回退 Open-Meteo —— 保持"开箱即用、不填 Key 也能跑"的体验；
- 和风的 WMO 与国内天气现象编码不同，`wmo_text()` 需要加一张映射表。
